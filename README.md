# 🎬 Movie Theater App (Learning .NET Technologies)

This project is a **Movie Theater API** built using **.NET**, following the **CQRS (Command Query Responsibility Segregation) pattern** with **MediatR**. The primary goal of this project was to explore modern **.NET backend development practices**, including (among others things):

- **CQRS with MediatR**
- **Unit of Work & Repository Pattern**
- **Swagger API Documentation**
- **xUnit for Unit Testing**
- **AutoMapper for Object Mapping**
- **.NET Core Web API**

## 🚀 Technologies Used (among others things)

- **.NET Core / ASP.NET Core** – Web API development  
- **Entity Framework Core** – ORM for data access  
- **MediatR** – CQRS implementation for clean architecture  
- **Unit of Work & Repository Pattern** – Abstraction for database interactions  
- **Swagger (Swashbuckle)** – API documentation  
- **xUnit** – Unit testing framework  
- **AutoMapper** – Automating object-to-object mapping  

## 📌 Project Overview

This API provides CRUD operations for managing a **Movie Theater system**, including **Movies, Showtimes, and Bookings**. The project follows a **clean architecture** approach using **CQRS with MediatR** to separate read and write concerns.

### **🔹 Features**
- ✅ **Movie Management** (Create, Read, Update, Delete)  
- ✅ **Showtime Scheduling**  
- ✅ **Booking System** (Reserve and Cancel tickets)  
- ✅ **CQRS Implementation** (Separate commands & queries)  
- ✅ **Unit of Work with Repository Pattern**  
- ✅ **Swagger API Documentation**  
- ✅ **Unit Tests with xUnit**
